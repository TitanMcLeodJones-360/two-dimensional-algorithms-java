# Two-Dimensional Algorithms

A Java project that performs common operations on 2D arrays (matrices).

## Features

- Find largest value
- Find smallest value
- Calculate total and average
- Count occurrences of a value
- Calculate column totals
- Reverse rows
- Shift columns upward
- Detect duplicate values in rows
- Generate consecutive pairs
- Print matrix contents

## Skills Demonstrated

- Java
- Object-Oriented Programming
- 2D Arrays
- Nested Loops
- ArrayLists
- Algorithm Development

## Concepts Learned

This project was completed as part of AP Computer Science A and focuses on traversing and manipulating two-dimensional arrays.
